A command-line tool that reads a task file, computes the critical path, and renders a themed chart to PNG, SVG, PDF, or interactive HTML. It draws dependency arrows, milestone diamonds, a percent-complete overlay, and a today marker, and it rejects missing fields, unknown dependencies, and dependency cycles with a readable message instead of a stack trace.
