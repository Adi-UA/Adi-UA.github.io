A shared daily safe-word service with Google OAuth, timezone-aware rotation, JNI-based Rust word generation, Bucket4j rate limiting, Prometheus metrics, and a Helm chart for Kubernetes deployment. Built with Java 21, Rust (JNI), Spring Boot, React, and SQLite. Packaged in a 4-stage Dockerfile.
